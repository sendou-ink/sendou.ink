In-game names now should accept exactly the characters the game allows

- More symbols such as ■, □, ● and ― are now allowed
- Lookalike characters the game doesn't have were removed from the picker
- Existing names using them were switched to the matching in-game character where possible
- Typing a lookalike converts it automatically (e.g. ' becomes ’)
