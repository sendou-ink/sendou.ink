The broadcast theme designer has settings, no CSS needed

- Pick a preset, then change its colors, fonts, corners, animation timing and weapon images from simple inputs
- Set a background image for the full screen scenes
- Each scene's sizes and spots (e.g. how tall the scoreboard is) show as number inputs when you preview it
- Custom CSS is still there under "Advanced", with the scene's default CSS next to it to copy from
